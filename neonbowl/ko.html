NEON BOWL 개인정보처리방침

시행일: 2026-11-15 · English

『NEON BOWL』(이하 "앱", 패키지 com.almightyhg.neonbowl)은 계정·회원가입 없이 동작합니다. 혼자 하는 경기, 월드 투어, 연습의 기록과 설정은 사용자 기기 내부에만 저장됩니다. 서버로 정보를 보내는 기능은 사용자가 직접 고르는 「친구와 하기」(온라인 친구 대전) 하나뿐입니다.

닉네임과 경기 정보는 같은 방에 들어온 참가자에게만 보입니다. 방에 들어오려면 6자리 방 코드가 필요합니다. 이 정보를 판매하거나 광고·분석 목적으로 제3자에게 제공하지 않습니다.

2. 처리 위탁과 국외 이전

친구와 하기의 서버는 Google LLC 의 Firebase(익명 인증·Cloud Firestore)를 사용합니다. 경기 데이터는 Cloud Firestore 서울 리전(대한민국)에 저장되며, 익명 인증과 서비스 운영 과정에서 Google 이 접속 IP 등 표준 기술 정보를 국외에서 처리할 수 있습니다. 모든 전송은 암호화(HTTPS)됩니다. Firebase 개인정보 보호 안내가 적용됩니다.

3. 보유 기간과 삭제

방 데이터는 경기 진행을 위해 저장되며, 현재는 경기가 끝난 뒤에도 서버에 남아 있을 수 있습니다. 삭제를 원하시면 아래 이메일로 닉네임과 방 코드(알고 있다면)를 보내 주세요. 확인 후 해당 방의 데이터를 지체 없이 삭제합니다. 기기에 저장된 기록은 앱을 지우거나 안드로이드 설정 > 애플리케이션 > NEON BOWL > 저장공간에서 데이터를 삭제하면 지워집니다.

4. 광고·결제·분석

앱에는 광고, 유료 결제·구독, 사용 분석 도구가 없습니다. 광고 ID 를 사용하지 않습니다.

5. 아동의 개인정보

본 앱은 만 13세 미만 아동을 주 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 닉네임에는 실명 등 개인을 알아볼 수 있는 정보를 쓰지 않기를 권장합니다.
