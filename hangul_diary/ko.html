한글일기(Hangul Diary) — 개인정보처리방침

시행일: 2026-08-16 · English

"한글일기"(이하 "앱")는 계정·회원가입 없이 동작합니다. 사용자가 작성한 일기와 모든 콘텐츠는 사용자 기기에만 저장됩니다. 개발자는 개인정보를 수집·보관하는 서버를 운영하지 않습니다.

1. 수집하는 정보

개발자는 개인정보를 수집·저장하지 않습니다. 다만 아래 기능을 사용할 때 해당 데이터가 외부 서비스로 전송되어 처리됩니다.

기능전송 데이터수신자목적
AI 첨삭·힌트·대화일기 본문(프라이버시 모드 시 요약만)Google (Firebase AI Logic / Gemini API)첨삭·힌트·대화 생성
오늘의 사진일기에서 추출한 영어 검색 키워드Pexels / Unsplash사진 후보 검색
광고광고 ID 및 광고 SDK 표준 데이터Google AdMob광고 게재(EEA/UK 는 동의 후)

2. 기기에만 저장되는 데이터

일기, 첨삭 결과, 표현 노트, 대화 기록, AI 기억, 설정은 앱의 로컬 저장소에만 보관되며 앱 삭제 시 함께 삭제됩니다. 백업은 앱 내 "데이터 내보내기"를 이용하세요. 안드로이드 자동 백업은 꺼져 있습니다.

3. 내 API 키 (BYOK)

설정에서 본인의 Gemini API 키를 등록하면 기기의 보안 저장소에만 보관되며 Google API 호출에만 사용됩니다.

4. 국외 이전

위 수신자(Google, Pexels, Unsplash)는 데이터를 국외에서 처리할 수 있으며, 각 사의 개인정보처리방침이 적용됩니다.

5. 아동

이 앱은 아동을 대상으로 하지 않습니다.

6. 데이터 삭제

모든 데이터는 기기에 있으므로 앱에서 삭제하거나 앱을 제거하면 즉시 삭제됩니다. AI 대화 기억은 설정 > AI 기억 관리에서 개별·전체 삭제할 수 있습니다.
