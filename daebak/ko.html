대박 일기(Daebak) — 개인정보처리방침

시행일: 2026-11-09 · English

"대박 일기"(이하 "앱")는 계정·회원가입 없이 동작합니다. 사용자가 작성한 일기와 모든 콘텐츠는 사용자 기기에 저장됩니다. 개발자는 개인정보를 수집·보관하는 서버를 운영하지 않습니다. 다만 AI 기능을 사용하면 아래 표와 같이 일기·대화의 일부 또는 전부가 Google 의 AI 로 전송되고, 일기 내용이 없는 앱 이용 통계가 Google Analytics 로 전송됩니다.

1. 수집하는 정보

개발자는 일기·대화 등 사용자가 작성한 내용을 수집·저장하지 않습니다. 다만 아래 기능을 사용할 때 해당 데이터가 외부 서비스로 전송되어 처리되며, 이 중 이용 통계(Google Analytics)는 개발자가 Google 이 제공하는 통계 화면으로 확인합니다.

프라이버시 모드의 적용 범위 — 설정의 "대화에 일기 원문 대신 요약만 보내기"(프라이버시 모드)는 AI 대화에서 오늘 일기를 보내는 부분에만 적용됩니다. 켜면 오늘 일기 대신 그 일기의 첫 문장을 최대 약 180자까지 그대로 보냅니다(AI 가 만든 요약이 아닙니다). AI 첨삭·첨삭 직후 자동 처리·힌트·즉석 질문·대화 요약, 그리고 대화에 함께 보내는 과거 일기 발췌·AI 기억에는 적용되지 않으므로, 이 기능들을 사용하면 위 표의 내용이 그대로 전송됩니다.

Google 의 AI 처리 — AI 기능으로 보낸 내용에는 Google 의 Gemini API 약관이 적용됩니다. Google 은 약관 위반을 감지·방지하기 위해 요청과 응답을 일정 기간 기록할 수 있고, 무료 등급으로 처리되는 요청은 Google 이 제품 개선에 사용하며 사람이 검토할 수 있습니다. 설정에서 본인 API 키(BYOK)를 쓰면 그 키의 등급이 적용됩니다. 그러니 주민등록번호·건강 정보 같은 민감한 정보는 일기에 적지 않는 것을 권합니다.

2. 기기에 저장되는 데이터

일기, 첨삭 결과, 표현 노트, 대화 기록, AI 기억, 설정은 앱의 로컬 저장소에 보관되며, 개발자 서버로는 보내지 않습니다. 다만 대화 기록·AI 기억·과거 일기의 일부는 위 표와 같이 대화 생성·요약을 위해 Google 의 AI 로 전송됩니다. 앱 삭제 시 기기의 데이터는 함께 삭제됩니다. 백업은 앱 내 "데이터 내보내기"를 이용하세요. 안드로이드 자동 백업은 꺼져 있습니다.

3. 내 API 키 (BYOK)

설정에서 본인의 Gemini API 키를 등록하면 기기의 보안 저장소에만 보관되며 Google API 호출에만 사용됩니다.

4. 국외 이전

위 수신자(Google, Pexels, Unsplash)는 데이터를 국외에서 처리할 수 있으며, 각 사의 개인정보처리방침이 적용됩니다.

이용 통계는 Google LLC(미국)가 운영하는 Google Analytics for Firebase 로, 앱을 쓰는 동안 수시로 암호화된 네트워크(TLS)를 통해 전송되어 미국 등 Google 데이터센터에서 처리됩니다. 이전 항목·목적은 1조 표의 "이용 통계" 행과 같고, Google Analytics 의 데이터 보존 기간(2개월)이 지나면 삭제됩니다.

5. 아동

이 앱은 아동을 대상으로 하지 않습니다.

6. 데이터 삭제

기기에 저장된 데이터는 앱에서 삭제하거나 앱을 제거하면 즉시 삭제됩니다. AI 대화 기억은 설정 > AI 기억 관리에서 개별·전체 삭제할 수 있습니다. 이용 통계는 앱 인스턴스 ID 로만 묶여 개발자가 특정인을 알아볼 수 없으며, 보존 기간이 지나면 자동으로 삭제됩니다. 앱을 삭제했다가 다시 설치하면 새 ID 가 쓰입니다.
