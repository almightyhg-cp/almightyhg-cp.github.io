끄덕사전 개인정보처리방침

시행일: 2026-08-26 · English

『끄덕사전 - IT 실무 용어사전』(이하 "앱")은 계정·회원가입 없이 동작하며, 사전 내용과 학습 기록은 사용자 기기 내부에만 저장됩니다. 개발자는 사용자의 개인정보를 수집·보관하는 서버를 운영하지 않습니다.

1. 수집하는 정보

개발자가 직접 수집·저장하는 개인정보는 없습니다. 앱은 사전 검색과 열람을 인터넷 없이 수행합니다. 네트워크는 아래 한 가지 목적으로만 사용됩니다.

기능전송 데이터수신자목적
광고기기 광고 ID 등 광고 SDK 표준 데이터Google AdMob광고 표시 (EEA/영국은 동의 후)

2. 기기에만 저장되는 데이터

학습 상태(헷갈림 표시·퀴즈 기록·진도), 최근 본 용어, 용어 요청 목록, 알림 설정은 모두 기기 내부 저장소에만 저장됩니다. 앱 삭제 시 함께 삭제되며, 안드로이드 자동 백업은 비활성화되어 있습니다.

3. 용어 요청함

사전에 없는 용어를 요청하면 그 목록은 기기 안에만 쌓입니다. 자동으로 전송되지 않으며, 사용자가 앱 안에서 "메일로 보내기"를 눌러 직접 보낼 때에만 개발자에게 전달됩니다.

4. 광고와 데이터 국외 이전

광고는 Google AdMob 을 통해 표시되며, 광고 식별자 등 표준 데이터가 Google 로 전송되어 국외에서 처리될 수 있습니다. Google 광고 정책이 적용됩니다. 유럽경제지역·영국 사용자에게는 동의 절차가 선행됩니다.

5. 아동의 개인정보

본 앱은 아동을 대상으로 하지 않습니다.

6. 데이터 삭제 방법

모든 데이터는 기기 안에 있으므로 앱 제거로 즉시 삭제됩니다. 학습 기록만 지우려면 안드로이드 설정 > 애플리케이션 > 끄덕사전 > 저장공간에서 데이터를 삭제하세요.
